# 2026 春季启元人工智能大赛诚信守则（Honor Code）

本人作为 2026 春季启元人工智能大赛参赛选手，郑重承诺严格遵守比赛规则及本诚信守则，秉持诚信、公正、独立、可复现的参赛原则，自觉维护比赛公平性与严肃性。本人充分理解并认可，违反本守则可能导致参赛资格被取消、比赛成绩作废等相应后果，并愿意承担由此产生的一切责任。

## 一、参赛诚信承诺

1. 本人保证提交的赛题 PR、`.skill` 文件、算子实现代码、测试、benchmark、报告和相关文档，均为本人在比赛期间独立完成，或在明确标注参考来源的基础上开发完成，不存在抄袭、剽窃、隐藏引用或其他作弊行为。

2. 本人承诺主动、全面、真实地披露实现过程中参考的外部资源，包括开源项目、技术文档、论文、官方示例、AI 工具辅助内容等，不隐瞒任何可能影响评审公平性的信息。

3. 本人保证不采用任何不正当手段获取比赛优势，包括但不限于窃取其他参赛选手成果、利用非比赛允许的工具或技术、与他人串通作弊、绕过隐藏测试或伪造测试结果。

## 二、参考资源说明

本人确认已按比赛要求，将本次赛题实现过程中涉及的参考资源单独记录至 `REFERENCE.md` 文件中。该文件将与本诚信守则一同作为提交材料。

`REFERENCE.md` 应包含以下信息：

1. 参考资源名称。
2. 参考资源链接（GitHub、Gitee、论文、技术文档等）。
3. 参考的具体内容，例如代码片段、算法逻辑、实现思路或文档说明。
4. 本人在参考基础上完成的独立开发、修改、调试、测试和优化工作。
5. 开源资源的许可证信息（如 Apache 2.0、MIT、BSD、GPL 等）。
6. 其他需要补充说明的信息。

## 三、禁止行为确认

本人明确知晓并承诺避免以下违反比赛公平性的行为：

1. 未经授权复制、抄袭他人代码、算法、文档或技术方案，且未进行明确标注。
2. 隐瞒、遗漏或虚假填写参考资源信息。
3. 与其他参赛选手或第三方串通，进行代码共享、答案交换或结果伪造。
4. 利用比赛平台漏洞、隐藏测试泄露、非授权 API、密钥或外部服务获取不正当优势。
5. 删除、绕过、篡改官方测试，或硬编码隐藏评测答案。
6. 伪造 benchmark、pytest、AOT build、generated source 检查等验证结果。
7. 其他违反比赛规则、公序良俗或学术诚信的行为。

## 四、责任与确认

1. 本人理解，比赛组委会有权对提交材料进行代码来源、参考信息、测试记录、benchmark 结果和可复现性审查。

2. 若本人违反本守则，愿意接受比赛组委会的相应处理，包括取消参赛资格、作废比赛成绩、公开通报等。

3. 若因本人违反本守则导致比赛争议、第三方权利受损或其他法律风险，本人将独立承担相应责任。

4. 本人确认已仔细阅读并完全理解本诚信守则全部内容，自愿签署并接受比赛组委会监督与审查。
