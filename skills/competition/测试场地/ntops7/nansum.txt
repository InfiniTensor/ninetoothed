     3. Reduction-Type Example Structures

     softmax (canonical reduction example)

     examples/softmax/kernel.py:
      import ninetoothed
      import ninetoothed.language as ntl
      from ninetoothed import Symbol, Tensor

      BLOCK_SIZE = Symbol("BLOCK_SIZE", constexpr=True)

      def arrangement(input, output, BLOCK_SIZE=BLOCK_SIZE):
          return input.tile((1, BLOCK_SIZE)), output.tile((1, BLOCK_SIZE))

      def application(input, output):
          row_minus_max = input - ntl.max(input)
          numerator = ntl.exp(row_minus_max)
          denominator = ntl.sum(numerator)
          output = numerator / denominator

      tensors = (Tensor(2, other=float("-inf")), Tensor(2))
      kernel = ninetoothed.make(arrangement, application, tensors)
     Key patterns:
     - 2D tiling (1, BLOCK_SIZE) -- one row at a time
     - Tensor(2, other=float("-inf")) -- fills partial tiles with -inf for
     stable max
     - BLOCK_SIZE = input.shape[-1] -- entire row fits in one tile
     - Numerically stable: subtract max before exp

     examples/softmax/torch_impl.py:
      import torch
      from examples.softmax.kernel import kernel

      def softmax(input):
          output = torch.empty_like(input)
          kernel(input, output, BLOCK_SIZE=input.shape[-1])
          return output

      def arrangement(x, w, eps, y, BLOCK_SIZE=BLOCK_SIZE):
          def arrange(tensor):
              return tensor.tile((1, BLOCK_SIZE))
          return arrange(x), arrange(w), eps, arrange(y)

      def application(x, w, eps, y):

   4. 分块策略（归约维度 > tile 容量时）

   nansum 复用 reduction.arrangement，天然支持大维度分块：
    reduction.arrangement 的分块流程:
      1. permute: 将归约维度移到最后
      2. flatten: 将多个归约维度压平为 1D
      3. 内层 tile: tile((1,...,1, block_size))   ← 每次处理 block_size 个元素
      4. 外层 tile: tile((1,...,1, -1))           ← 覆盖整个归约维度
      5. squeeze: 压平非目标维度，生成 2D 程序空间
   在 application 中的分块累加：
    def application(input, output):
        accumulator = ntl.cast(0, ntl.float32)       # fp32 累加器
        for i in range(input.shape[0]):              # 遍历所有 chunk
            block = ntl.cast(input[i], ntl.float32)  # 当前 chunk → fp32
            block = ntl.where(block != block, 0, block)  # NaN → 0
            accumulator += ntl.sum(block, axis=0)    # 累加当前 chunk
        output[0] = ntl.cast(accumulator, dtype)     # 转回输出 dtype
   全局归约 (dim=None) 使用递归策略：
   - block_size=1024（最优值，由 tile sweep 确认）
   - 每轮将 N 个元素归约为 ceil(N/1024) 个
   - 递归直到 numel==1（如 64×8192=524K → 512 → 1，两轮）

   block_size 选择：next_power_of_2(dim_size)，clamp 到 [32, 1024]。

   性能分析：
   - dim 归约：ntops kernel 恒定 ~0.038ms（Triton launch overhead + NaN
   处理），torch 的 C++/CUDA kernel 为 ~0.013ms
   - global 归约：ntops ~0.060ms（2 轮递归），torch 在大 size
   时也较慢（0.033-0.043ms），speedup 最高 0.72x
   - NaN 处理开销：全 NaN vs 正常数据性能无差异，block != block 模式高效
   - 非连续输入：无性能退化，stride 通过 reduction.arrangement 正确传播
   - 优化尝试：tile sweep（128-4096）、num_warps（1-16），block_size=1024 +
   num_warps=8 为最优

   7. 关键实现细节

   NaN 检测：使用 block != block 模式（IEEE 754 NaN 的唯一自比较为 False），与
   ntops.kernels.isnan 一致。

   fp32 累加器：所有中间求和均在 float32 中完成，最终 ntl.cast 回输出
   dtype，防止 fp16 大数累加溢出。

   Partial tile 处理：Tensor(ndim, dtype=dtype, other=0) 将越界位置填
   0，不影响求和结果。
