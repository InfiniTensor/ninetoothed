# 合入上游目标架构后的 RTX 4090 验证

2026-09-16 对提交 `1b68040f73553de9b5929cd61067c4d4369f7f22` 补充 NVIDIA 实机验证。该提交已合入上游 `22e74c3`。

## 结果

- 真实 Triton GPU 差分 **15/15 通过**，覆盖 9 个程序、10 类行为。
- 在同一源码与环境下，按测试 ID 核对的完整集合为 **902 项：900 passed、2 skipped**。
- 两项跳过均要求至少两张 CUDA GPU；本次使用单张 RTX 4090。

完整集合由一次中断运行的 898 passed、2 skipped，以及随后精确补跑通过的 2 项组成。核对工具拒绝重复、遗漏、失败及源码/环境变化；一个无名称的 setup 残留不计为通过。这不是一次未中断的全仓库运行，15 项差分也不另行累计。

## 复现与追溯

[固定证据归档](https://github.com/a962695448-rgb/ninetoothed/tree/c5b216200a2c4ce58566cd535ae35d7cbabdbd19/docs/validation/rtx4090-20260916)包含原始 JUnit、完整收集清单、逐项核对结果、环境、命令和执行脚本；支持无需 GPU 的再次核对。

环境为 RTX 4090 / sm89、Python 3.12.3、PyTorch `2.6.0a0+ecf3bae40a.nv25.01`、CUDA 12.8、Triton 3.1.0、NumPy 1.26.4、SymPy 1.13.1。Triton 来自镜像中的 NVIDIA `pytorch-triton` 发行包。

单独补跑的是 `tests/test_conv2d.py` 中 padding=(0,1) 与 padding=(2,0) 的 FP16 用例。未修改测试参数、`max_num_configs=50` 或 rtol/atol=0.001。两项逐项运行共用时 1222.67 秒。

初次全量运行的超时、中断记录，以及并行诊断中两个 worker 退出的记录均保留。后续通过独立文件记录调用栈并逐项补齐；未对 worker 退出的底层原因作未经证实的归因。

## 结论范围

本次补充当前上游组合的 RTX 4090 正确性证据。它不是新 A100 记录，也不是性能基准；补跑阶段的覆盖率文件不代表完整仓库覆盖率。历史 A100 结果仍对应旧计算源码 `ed33273`。

CPU 顺序解释不模拟 GPU 竞争；操作、dtype、访存支持范围和定位结论仍遵守原有验收说明。本轮仅补充验证材料，未变更计算源码、测试断言或依赖声明。
