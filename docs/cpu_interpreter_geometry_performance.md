# 无跟踪矩阵乘的提取几何缓存

## 改动与边界

基线为 90197b02e91f056bb6a7f6204dbdfbec2270e347。仅在无 trace、callback、watch、handlers 和事件过滤器的 scalar matmul 解释执行中，复用单个 TensorRef 的末级 extract 地址图。每项缓存最多 65536 个逻辑元素，执行结束随内部引用释放；只存地址与 mask，不缓存用户数组数值。

缓存键包括布局身份、外层/提取坐标、shape/stride/dtype、带类型的符号绑定和实际编译求值计划。只接受能证明各中间结果属于有符号 int64 范围的基本整数/布尔表达式；除法需正除数。自定义数字对象、函数调用、浮点式、未证明的溢出/警告路径、空/大逻辑图继续逐次求值。数组内容仍逐次读取，输出仍是新数组，公开 read/write/offset 路径保持原有语义。

## 三轮独立 CPU 比较

macOS arm64 / Python 3.12.14 / NumPy 2.3.5 / SymPy 1.14.0，无 Torch/Triton。每轮旧/新采用独立进程、次序交替，7 样本 × 3 次执行。主要指标是预先构建的公共 interpret_program 执行；输出与独立 NumPy 公式及输入不变检查通过。另测冷表达式/dtype缓存执行及 tracemalloc 峰值。

| 矩阵乘 M×K×N | 旧版热执行 ms | 新版热执行 ms | 三轮加速范围 |
|---|---:|---:|---:|
| 7×16×7 | 129.39–129.94 | 36.04–36.40 | 3.570–3.599× |
| 9×32×11 | 514.87–516.41 | 126.69–127.25 | 4.046–4.076× |
| 5×17×9（K 补齐） | 234.29–235.12 | 59.64–59.86 | 3.919–3.942× |

各轮三个目标的几何平均为 **3.851238 / 3.859573 / 3.847211×**，均超过预定 1.10×。33 个计时条件全部满足至多 5% 退化限值；最小控制比 0.963851，对应约 3.75% 耗时增加。7 个程序 × 3 轮完整轨迹指纹一致；大目标的 trace=True 也单独核对，未把其时间列为优化收益。独立审计再次复算通过。

这些是特定小矩阵的 CPU 解释器执行收益，不是 GPU 内核、模型端到端或所有程序的加速；不同历史优化的比值不得相乘。

## 内存代价

三个目标的热执行 tracemalloc 峰值从约 283–365 KB 增至 424–548 KB，增加约 **141–183 KB（49.9%–53.3%）**。这来自执行期间保留地址图，换取重复标量提取省去地址重建。它不是进程 RSS；冷缓存结果另存，不能从热执行数据推出冷启动收益。缓存有单项和作用域限制，但不声称内存降低。

## 语义回归与初版缺陷

最终 23 项专项在 -W error 下通过，完整无 Torch/Triton CPU 选择范围 **793 passed / 15 GPU deselected**；Ruff、format 和项目贡献风格通过。

初版三轮计时通过，但审查发现形状证明提前覆盖 outer_index/extract 符号，与 TensorRef.shape 的原始符号上下文不一致。两个回归确实复现了先忽略除零、再要求抛错时异常被缓存掩盖。最终版先在原符号中证明 extent，随后只对地址式加入坐标覆盖，两个回归转为通过。初版未发布，源、初次测试搭建错误、缺陷复现、初版性能全部保留；最终性能来自修正后的新三轮。

## 实际 GPU 验证

RTX 4090 D / Python 3.12.3 / NumPy 1.26.4 / Torch 2.6.0a0 / CUDA 12.8 / Triton 3.1.0 环境：现有 **15/15 GPU 差分通过**；另三个计时尺寸的实际 Triton GPU、原始 SSA、目标 SSA 和 NumPy 比较全部通过，输出 guard 与输入不变检查通过，最大绝对误差 0。三个尺寸分别观测到 1560、6318、2868 次地址图复用。

同环境的几何/布局/表达式语义回归 **131 passed in 1.50s**。这些语义测试执行解释器，不能计为 131 个 GPU 内核案例。201 个冻结输入文件在实机运行前后保持一致；11 份原始记录无损回收并逐文件校验。此轮不重跑全库卷积集合，历史 A100/完整 GPU 集合保持各自源码范围。
