# 提取地址缓存的命中路径与相关符号键

基线为已发布的 c2c35ec875ca3cb30f80c23d06d4fb8d127d9dd7。此轮优化 CPU 解释器，GPU 编译器和内核生成逻辑保持原样。

## 剖析与改动

9×32×11 的无跟踪 scalar matmul 中，6336 次几何访问仍触发 85536 次整数区间构造和 38016 次临时根计划键生成器调用。cProfile 只用于找到重复工作，其插桩耗时不作为性能收益。

最终实现保留 shape/stride/dtype、外层与提取坐标、带类型的相关符号以及实际编译计划作为键。区间证明只在 miss 时构造，受信布局复用根表达式的身份键。只收集形状与地址表达式引用的符号；映射中的所有键仍须是普通字符串，避免自定义键的相等比较副作用被跳过。符号删除、类型变化、求值计划重编译仍触发检查或退回原计算；数组内容不进入缓存，跟踪/回调模式保持逐次计算。

## 初稿未采用
